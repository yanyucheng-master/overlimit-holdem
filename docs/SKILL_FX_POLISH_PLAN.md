# 全技能特效精修定稿

日期：2026-09-13。用户授权自行制定、定稿并完成全部技能，完成后统一审阅。范围以本地 `/api/skills` 为准：33 项，包含 23 个独立普通技能、终局和 9 个协议技能。采用单人实施，不使用子代理。

## 定稿方向

以深渊能量、晶体折射和刻蚀金属构成统一材质。每个普通技能拥有独立主体和动作，释放、传递和命中对应同一种物理含义。图案由可缩放矢量绘制，柔软能量材质使用一张可复用透明纹理。删除被替代的通用框线绘制，保持必要的目标标记、结果文字与持久状态。

调度、锚点、时长和五阶段时间线沿用现有系统。高档提供分层主体、短弧轨迹和少量有方向的碎片；低档保留同一主体的简化静态形态与短淡入，不退回通用方框。公开结果先经过现有匿名化，再选择统一中性图形，不能从图案、运动、目标或纹理暴露私有技能。

终局保持独立入口，不加入普通技能注册表；精修宣告封印与执行斩痕，保持共享展示窗口、重连静态恢复及结算顺序。9 个协议保留共同的公开结算仪式，并按公开牌型绘制对应的组合纹章。

## 执行顺序

1. 制作共用透明能量纹理与独立矢量主体库。
2. 接入普通技能、公开结果与协议分支，完成释放、轨迹、命中的统一材质和独立动作。
3. 精修终局独立表现，保留原有时间与恢复行为。
4. 集中检查全部 33 项、关键分支与高低档；一次相关逻辑回归和真实页面批量截帧，发现问题只复查受影响项。
5. 交付可逐项播放的审阅入口、代表性录屏／截图、覆盖记录与实现说明。实施阶段不自动提交或推送 GitHub；发布以用户后续明确授权为准。
