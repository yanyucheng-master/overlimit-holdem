## 第一部分：统一全局高／低两档（已完成）

- 设置名称改为“视觉效果”，只保留高、低；移除中档、“减少动态效果”和“低性能模式”两个独立开关。
- 高档保留现有完整演出；低档合并少运动、少装饰、轻渲染策略，关闭装饰粒子、震屏、强闪烁、持续背景运动及高开销模糊，保留即时控件反馈、技能发生和结果提示。
- 运行时、样式和开发预览都使用同一套两档策略；低档不通过拉长动画时长实现。
- 迁移规则：旧中档转低；旧 reduceMotion 或 lowPerformance 为 true 转低；其他明确的高、低选择保留。首次无有效选择时，系统 prefers-reduced-motion 为 reduce 默认低，否则高；保存后尊重用户选择。仅从新设置中移除废弃字段，语言、音量等现有设置保持原值。
- 保持服务端规则、技能语义、信息可见性和 presentation barrier 不变；低档缩短动态演出后，仍保留静态结果直到共享展示窗口结束。
- 更新相关中英文文案、设置/特效测试与预览工具；验证首次默认、旧设置迁移、刷新持久化、档位切换、低档可读性和终局同步。
- 验证：单元测试；视觉设置专项浏览器检查；现有 Skill FX、UI、交互、联机和 i18n 回归。提供设置截图和实际检查结果。

## 第二部分：大厅及附属界面交互升级（已完成）

目标：按下立即回应、松开利落回弹、状态变化明确确认；不新增音效或背景循环动画。

范围：大厅、技能构筑及详情、设置、规则、教程及图片查看器、匹配与加入房间弹窗。保留布局、暗色紫金氛围和四种模式各自的匹配／人机／建房直达入口。

- 高档：悬停 120ms；按下 70ms，按钮视觉表面缩至 97%、卡片至 98.5%；回弹 180ms；选中确认 220ms；弹窗进／出 180／120ms；大厅与技能构筑切换 220ms。
- 低档：即时亮度、边框变化及约 80ms 的短淡入，不做明显位移和弹跳。直接复用第一部分的两档配置。
- 统一反馈控制器，保持点击区域与布局稳定；取消按压、触屏滚动、失焦时清理反馈，一次操作只触发一次业务行为。
- 技能目录按技能 ID 复用节点，选择时更新状态，保留焦点和滚动位置；筛选按原有规则回顶。
- 统一附属界面过渡，保留遮罩、Esc、inert、焦点约束和返回逻辑，兼容快速反向操作。
- 主面板／卡片／常规控件圆角为 24／16／12px，弱化内层套框、补充轻微高光与阴影。
- 操作标题、卡片和按钮禁止误选；输入框、规则正文、技能详情及可复制信息保留选择，教程拖拽缩放保持正常。
- 验收桌面 1440×900、手机模拟 390×844、窄屏 320×700、中英文和高／低档，交付可操作版本、静态对比及交互录屏；区分手机模拟和实机验收。
