## 当前真源与行为

2026-10-05 接入前，前端只有 54 Hz 环境振荡器，没有歌曲播放引擎。实现保留音效和现有音量设置，替换音乐部分。

音乐判断使用服务端已公开的状态和事件：`room_state.skillState.endgameActive`、`skill:state.room.endgameActive`、成功的 `skill:resolved` 终局公开数据，以及公开 ALL IN 行动/公开玩家标记。不得借音乐泄露被「遮蔽」隐藏的对手全下状态。

终局有效时优先于 ALL IN。终局失效或收到权威 `hand_result` 时终止终局并恢复 B，本手不再因既有 ALL IN 标记恢复 C2。新的一手清除该限制。常规手结束也恢复 B。终局的 `ENDGAME_EXECUTION` 屏障期间虽然 phase 为 showdown，尚未发出 hand_result，继续终局音乐到真实结束。单纯的终局选择窗口、技能预览、失败/被反制的发动请求不触发 D5。

歌曲在大厅、等待/构筑和牌桌界面播放。大厅与等待共用 L1，切页不重播；正式开局选择牌桌曲，退出牌桌恢复 L1 的独立播放位置。隐藏页面暂停；大厅/创建房间的曲目不依赖网络与对局快照，牌桌掉线则暂停。进行中的牌局短暂经过重连等待室时保留原牌桌曲目，收到权威快照后续播。相同场景与重复同步不重启曲目；暂停/音量关闭后恢复不重播终局开场；刷新重连到已生效的终局也不重新宣令。

首次用户手势解锁 Web Audio。新设备音乐音量默认 35%，保留已保存的音量（包括 0）。音乐状态显示真实加载、播放、关闭、暂停或失败，并提供重试。音频失败不得阻断下注或技能流程。

## 交付与证据

完成于北京时间 2026-10-06。运行资源在 `public/assets/audio/`，共四段音频、FLAC/MP3 各一份。四段 FLAC 解码的 PCM 与批准 WAV 完全相等，资源及母版散列见 `public/assets/audio/provenance.json`。

播放器为 `public/table-music.js`。只替换旧环境振荡器，沿用共享 AudioContext 和独立音效音量。D5 的 12.936354 秒一次段由 3.16 秒慢开场与 9.776354 秒快段入场组成，两段运行音源在同一音频时钟提前排程，后续只循环 42.664625 秒快段。Chrome 对短 MP3 一次段解码会保留 30 个额外采样（0.625 毫秒），播放器按母版时长去除尾部填充，不进行变速。无损首个连续交接与后续两次循环经真实 Web Audio 离线渲染对照，最大误差约 `1.46e-11`；这证明播放排程和采样对应关系，不代替人耳接缝评价。

21 项 Jest 测试通过（音乐控制及兼容性 15 项、既有终局屏障 5 项、经典连续两手回归 1 项）。实际游戏浏览器检查通过，包含真实公开 ALL IN 行动、遮蔽信息边界、成功 ENDGAME、处刑屏障与权威 hand_result、终局失效后全下仍在、后台/静音/断线/刷新、资源失败重试、中英文切换、320/390 像素设置视图与离桌停止。检查记录含 19 次阶段/场景观察。后台可见性、技能失效及特定处刑牌面采用独立验证服务器中的可控夹具；D5 宣令计时器只在该验证环境延长，以观察完整一次段。没有将这些验证入口加入正式游戏。

另在普通 Chrome 真实人机桌通过界面确认 B 播放、音量与设置，截图 `artifacts/bgm-integration-20261005/chrome-game-music.png`。现有 `verify-i18n.mjs` 检查通过，8 份运行资源完整解码通过。报告、截屏及详细交付说明见 `artifacts/bgm-integration-20261005/`。

## 2026-10-07 大厅曲 L1

用户要求新增一首大厅专属 BGM，创建房间期间也播放。在 Chrome 的 Flow Music 生成《入席之前 / Before the Deal》，模型 Lyria 3.5，Instrumental，请求 100 BPM、2:00、Auto seed。独立曲目来源：`https://www.flowmusic.app/song/a7139029-4759-4b1d-a4be-e4c1fa45198c`。按用户此前明确要求，不观察余额。生成前的英文提示词、可见提交参数、原件、处理报告及截图保存于 `artifacts/bgm-lobby-20261007/`。

原件完整解码 122.208 秒，48kHz 立体声，节拍估计约 102.001 BPM，保留原始速度。循环选取 9.435188 至 87.081375 秒，以约一小节（2.352917 秒）余弦权重交叠并旋转到连续采样边界，形成估计 32 小节、75.293271 秒周期。选择依据是稳定节拍、头尾音级特征相似度约 0.9951、边界能量差约 0.112 dB 及规整周期；这些数值不证明乐句或主观转场自然。恒定增益 -5.32 dB，WAV/FLAC 母版 -21.35 LUFS、-5.39 dBTP；MP3 兼容版 -21.62 LUFS。另留尾部 12 秒到头部 12 秒的接缝试听。

新增 `l1-before-the-deal-loop.flac` 与 `l1-before-the-deal-loop.mp3`，FLAC 的 PCM 与 WAV 母版完全相同；此前 8 个 B/C2/D5 运行文件的 SHA256 不变。`provenance.json` 只追加 L1，并明确标记待用户试听；不能将这首新曲视为用户已经认可的定稿。两种格式在 Chrome 解码后都为 3,614,077 帧，真实播放器经 Web Audio 离线渲染三轮（两次接缝）与各自解码采样最大误差为 0。

播放器以当前屏幕选择 L1 或牌桌导演的 B/C2/D5。首次大厅在 HTML 中已激活，但尚无 `dataset.screen`，因此补齐初始化判断。`auth`、`wait`、`skillLab` 使用固定大厅 cue；进入牌桌时同时更新曲目和快照权限，避免用大厅的权限提前播放。两个常驻场景各自保存位置，解码缓存最多 4 段，可容纳 L1、B 与 D5 的一次/循环对。重连等待室另保留进行中的牌桌 cue，避免切到 L1 后重新播放终局宣令。界面设置的当前曲名和中英文状态同步更新。
