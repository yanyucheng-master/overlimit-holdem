## 当前真源与行为

当前前端只有 54 Hz 环境振荡器，并没有歌曲播放引擎。保留音效和现有音量设置，替换音乐部分。

音乐判断使用服务端已公开的状态和事件：`room_state.skillState.endgameActive`、`skill:state.room.endgameActive`、成功的 `skill:resolved` 终局公开数据，以及公开 ALL IN 行动/公开玩家标记。不得借音乐泄露被「遮蔽」隐藏的对手全下状态。

终局有效时优先于 ALL IN。终局失效或收到权威 `hand_result` 时终止终局并恢复 B，本手不再因既有 ALL IN 标记恢复 C2。新的一手清除该限制。常规手结束也恢复 B。终局的 `ENDGAME_EXECUTION` 屏障期间虽然 phase 为 showdown，尚未发出 hand_result，继续终局音乐到真实结束。单纯的终局选择窗口、技能预览、失败/被反制的发动请求不触发 D5。

歌曲在牌桌界面播放；离开牌桌停止，隐藏页面/掉线暂停，返回后按照最新权威状态恢复。相同场景与重复同步不重启曲目；暂停/音量关闭后恢复不重播终局开场；重连到已生效的终局也不重新宣令。

首次用户手势解锁 Web Audio。新设备音乐音量默认 35%，保留已保存的音量（包括 0）。音乐状态显示真实加载、播放、关闭、暂停或失败，并提供重试。音频失败不得阻断下注或技能流程。

## 交付与证据

完成于北京时间 2026-10-06。运行资源在 `public/assets/audio/`，共四段音频、FLAC/MP3 各一份。四段 FLAC 解码的 PCM 与批准 WAV 完全相等，资源及母版散列见 `public/assets/audio/provenance.json`。

播放器为 `public/table-music.js`。只替换旧环境振荡器，沿用共享 AudioContext 和独立音效音量。D5 的 12.936354 秒一次段由 3.16 秒慢开场与 9.776354 秒快段入场组成，两段运行音源在同一音频时钟提前排程，后续只循环 42.664625 秒快段。Chrome 对短 MP3 一次段解码会保留 30 个额外采样（0.625 毫秒），播放器按母版时长去除尾部填充，不进行变速。无损首个连续交接与后续两次循环经真实 Web Audio 离线渲染对照，最大误差约 `1.46e-11`；这证明播放排程和采样对应关系，不代替人耳接缝评价。

21 项 Jest 测试通过（音乐控制及兼容性 15 项、既有终局屏障 5 项、经典连续两手回归 1 项）。实际游戏浏览器检查通过，包含真实公开 ALL IN 行动、遮蔽信息边界、成功 ENDGAME、处刑屏障与权威 hand_result、终局失效后全下仍在、后台/静音/断线/刷新、资源失败重试、中英文切换、320/390 像素设置视图与离桌停止。检查记录含 19 次阶段/场景观察。后台可见性、技能失效及特定处刑牌面采用独立验证服务器中的可控夹具；D5 宣令计时器只在该验证环境延长，以观察完整一次段。没有将这些验证入口加入正式游戏。

另在普通 Chrome 真实人机桌通过界面确认 B 播放、音量与设置，截图 `artifacts/bgm-integration-20261005/chrome-game-music.png`。现有 `verify-i18n.mjs` 检查通过，8 份运行资源完整解码通过。报告、截屏及详细交付说明见 `artifacts/bgm-integration-20261005/`。

本地游戏地址：`http://127.0.0.1:4182/`。在项目目录可运行 `node scripts/preview-bgm-game.cjs` 重开预览；常规 `npm start` 同样使用这些正式资源。新设备默认 35%，原已保存 0 的设备继续关闭，需要在设置里自行调高。

验收中复现原有经典模式连续多手崩溃：结算建立的技能状态只有 settlement，下一手翻牌仍直接访问不存在的 burnedCards。将该访问改为与转牌/河牌路径一致的可选数组访问，补充真实引擎连续两手回归。不改变下注、结算或技能判定。

仍未完成移动真机扬声器、人耳全程实战混音与长时间疲劳度验收。三首音乐的主观选曲依据用户已给出的认可；代理没有直接听音频。
