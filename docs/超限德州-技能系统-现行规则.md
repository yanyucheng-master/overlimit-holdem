# 0. 阅读约定

- **标准下注贡献**：盲注、跟注、加注、标准 ALL IN 投入。进入底池，可被撤退退还，可被血战 / 绝境 / 绝路 / 协议 / 防守修正。
- **直接技能筹码转移**：贷款拿走的筹码、终局没收未匹配贡献等。不进倍率，撤退不退还，公平不回滚已完成转移。
- **技能事件**：一次合法、已扣费（若需要）并进入结算的主动发动，或一次真正触发的被动效果。
- **既定事实**：已看见的信息、已完成的换牌 / 牌堆修改、已发生的筹码转移。公平与撤退都不能时间倒流。
- **公开 / 秘密**：公开技能双方都知道发生了什么；秘密技能默认只对发动者可见，满足特定揭露条件时才可被确认。

# 1. 全局规则

## 1.0 全模式基础经济与牌型奖励

牌型基础奖励属于《超限德州》的游戏基础经济规则，不是技能效果。

无论：

- standard + skill off
- overdrive + skill off
- standard + skill on
- overdrive + skill on

只要最终通过 Showdown 决出胜者，就发放 launch-v1 牌型基础奖励。关闭技能只代表不启用技能系统，并不代表完全原版 Texas Hold'em。

| 牌型 | category | 奖励 |
| --- | --- | --- |
| 高牌 | 1 | +0 |
| 一对 | 2 | +0 |
| 两对 | 3 | +0 |
| 三条 | 4 | +25 |
| 顺子 | 5 | +50 |
| 同花 | 6 | +75 |
| 葫芦 | 7 | +100 |
| 四条 | 8 | +250 |
| 同花顺 | 9 | +400 |
| 皇家同花顺 | 10 | +500 |

- Fold / Retreat / 平局：不发牌型奖励。
- 皇家同花顺是正式独立牌型（category 10）。协议 P09 同时覆盖 category 9 和 10，不另设皇家同花顺独立协议。
- 牌型奖励不是「自己的技能倍率」，因此不阻止 Protocol。Blood / Desperation / Dead End 等已有自己的技能倍率时，仍按现有规则阻止自己的 Protocol。

正式结算顺序：

`standardPokerNet + handRankBonus + 其他基础加值（例如 Probe）→ 自身合法技能倍率 → 对手产生的合法倍率 → Defense → Stack Cap → 唯一整数筹码转移`

## 1.2 能量

| 项 | 现行值 |
| --- | --- |
| 开局能量 | 4 |
| 通常上限 | 8 |
| 携带天命时本人上限 | 10 |
| 对手界面显示上限 | 8（不直接显示 10） |
| 强运允许下限 | -4 |
| 负能量限制 | 除强运外，不能发动主动技能，也不能触发新的被动技能事件 |
| 普通公开快照 | `clamp(realFinalEnergy, 0, 8)` |

手牌结束自然恢复：

| 结果 | 能量 |
| --- | --- |
| 胜 | +1 |
| 败（含普通 Fold） | +2 |
| 平 | 双方各 +1 |
| 撤退 Fold | 撤退者 +0，对手 +1 |

公平成功后，本手全部结束恢复都被抑制，包括胜者 +1、败者 +2、平局双方 +1、深呼吸、绝境 +1、反制空放返还、资源型强运。

对手能量规则：**逐手公开、手内冻结。**

- 每手结束：所有能量恢复、Fairness 抑制、Fortune 资源效果等处理结束后刷新公开快照。结束阶段的私有能量偿还不实时公开；下一手初始化前统一重算公开快照，再发布新一手状态。负能量仍公开为 0，9 / 10 仍公开为 8。
- 下一手进行过程中：对手显示保持冻结，不实时变化。
- 普通对手可见值：真实 -4/-3/-1/0 → 0；真实 1~8 → 真实值；真实 9/10 → 8。
- 本人始终看到自己的真实当前能量，包括 Strong Fortune 负数和 Destiny 的 9/10。
- 灵视始终读取服务器真实当前能量（含负数、9/10 与手内实时变化），只写入私有结果，不得顶替对手信息条上的公开冻结值。
- 普通客户端不得通过任何其他字段区分真实 0 与被遮蔽的负数 0，也不得区分真实 8 与 Destiny 被封顶后的 8。

## 1.3 倍率与直接筹码

只修正**标准净筹码转移**。终局没收、贷款直接拿筹不进倍率。

常见乘法：

- 血战 ×2；双方血战 ×4
- 绝境获胜 ×3
- 绝路因对手普通 Fold ×3
- 协议获胜 ×2

叠加规则：

- 自己的血战 / 绝境 / 绝路 与 对手的血战 可乘法叠加
- 若本手已有**自己技能**产生的其他筹码倍率，自己的协议不触发
- 对手技能产生的倍率不阻止自己的协议
- 试探 +50 先并入基础标准收益，再参与倍率
- 最终支付不超过败方实际可支付筹码

## 1.4 反制、公平、绝密（总则）

- 主动技能默认可被反制；**公平不能被反制**。
- 反制捕获的是「下一次合法且已扣费的主动技能」，不是非法请求，也不是被动技能本身。
- 公平清除持续 / 预埋 / 待结算状态，封锁本手后续主动与新被动事件，并抑制本手结束恢复。已完成事实不回滚。
- 绝密保护的是本人底牌私人信息，不阻挡公共牌情报、灵视、纯技能元信息。

# 3. 主体技能

## 1 深呼吸 / Deep Breath

- 负载 1 / 费用 1 / 主动 / 秘密 / 每手 1 次
- 仅自己的合法下注回合，翻牌前至河牌
- 支付 1；若直到本手结束没有再发生自己的技能事件，结束时恢复 2
- Fold 后仍结算。无其他技能且自己 Fold：+2，再加败者 +2
- 可被反制。被合法阻止时，回收利用按 `floor(1 × 50%) = 0` 结算，不实际返还能量
- 公平清除待恢复状态并抑制本手结束恢复

## 2 回收利用 / Recycle

- 负载 2 / 费用 0 / 被动
- 本手结束时，在「已合法扣费且最终失败」的技能中取原始费用最高的一次，返还 `floor(费用 × 50%)`
- 符合：被反制、被绝密阻止、目标实际不存在或已离开合法区域
- 不符合：扣费前非法拒绝、取消、网络重发、反制空放未触发
- 不在中途返还。每手最多结算一次

## 3 恐吓 / Intimidation

- 负载 3 / 费用 4 / 主动公开 / 每手 1 次
- 前提：双方当前累计标准投入均未超过 500
- 本手禁止 Fold；每人累计标准投入最多 500；Bet/Raise 必须让对手仍可合法 Call
- 仍允许点 ALL IN，但标准投入最多加到累计 500，并记 `allInAction=true`；若筹码未全部投入则 `stackCommitted=false`
- 500 上限不管技能倍率造成的最终额外转移
- 恐吓下撤退状态可以存在，但不能撤退 Fold
- 恐吓下绝路仍可发动，但 Fold ×3 不会发生

## 4 绝境 / Desperation

- 负载 2 / 费用 0 / 被动
- 每手开始看手牌开始筹码快照：`<= 200` 则本手进入绝境
- 不按当前筹码、是否 ALL IN、是否落后动态触发
- 获胜：标准净收益 ×3，并额外 +1 能量
- 平局不触发。公平可清除待结算绝境，并抑制结束 +1

## 5 血战 / Blood Battle

- 负载 2 / 费用 3 / 主动公开 / 每手 1 次
- 本手标准净转移 ×2；双方都开则 ×4
- 平局不放大。最终不超过败方可支付筹码
- 公平可清除

## 6 防守 / Defense

- 负载 3 / 费用 4 / 主动秘密 / 每手 1 次
- 自己输掉且不是主动 Fold：最终净损失减半
- 赢、平、主动 Fold：无收益，4 费不退
- 结算时若确实把公开损失减半，可自然确认「防守」

## 7 感知 / Perception　**FROZEN_V1**

- 负载 3 / 费用 0 / 被动完全秘密
- 节点：底牌发完、Flop、Turn、River，四次独立判定
- 每手最多成功 3 次
- 触发概率随自身筹码劣势：均势 **25%** → 全劣 **50%**（`spec-25-50`）
- 先选信息类别，再 **75% 真 / 25% 假**
- 假命题必须在当前真实状态下确实为假
- 同手避免完全相同、等价或直接逻辑否定
- 灵视只能发现「本手发生过感知」，看不到内容与真假
- 绝密可阻止感知读取受保护底牌信息
- **未解冻前不得改这组概率**

## 8 情报 / Intel

- 负载 3 / 费用 4 / 主动秘密 / 每手 1 次
- 扣费前锁定模式
- A：系统随机看对手一张底牌，100% 真，不可自选左右；可被绝密阻止，失败后不能改看公共牌
- B：选择任意尚未发出的公共牌位置（含翻牌前看未来 River），100% 真；不受绝密影响

## 9 绝密 / Top Secret

- 负载 3 / 费用 3 / 被动秘密
- 每手默认 ON（ARMED），任一方回合都可主动关闭一次；关闭后本手锁定 OFF，不能重开。关闭不耗能、不占行动、不改变回合或计时，不触发警觉/反制，不打断深呼吸
- 戒备开启且允许新技能事件时，敌方读取 / 推断 / 交换 / 零化 / 操作私人底牌会被同步拦截：若能量 ≥ 3，自动付 3，锁定 ON（ACTIVE_LOCKED）并持续保护本手，后续不再收费；没有反应等待窗口
- 能量不足时攻击正常通过，戒备仍 ON，主动关闭机会仍保留；恢复到足够能量后可再次尝试触发，不许透支
- 阻挡：感知底牌信息、情报底牌、千术对手底牌、零化底牌
- 不阻挡：公共牌情报、灵视、纯技能元信息
- 攻击方只得到通用失败，不自动获知绝密或 ON/OFF/锁定状态；付费失败仍适用回收利用。真正启动是技能事件，会打断深呼吸，但不触发警觉/反制
- 公平清除保护并阻止本手新启动；绝路阻止新启动但不追溯取消已建立保护。重连保留本人选择，下一手重置 ON
- 公共手牌审计不披露绝密防御事件；灵视仍保留既有的真实能量和已发生技能查询权限，并非被底牌保护阻挡

## 10 反制 / Counter

- 负载 4 / 费用 4 / 主动秘密 / 仅翻牌前放置 / 每手 1 次
- 捕获对手下一次合法主动技能：对方照常扣费 → 技能失败 → 本手不能再主动、也不能再产生新被动事件
- 已完成效果不追溯
- 可以反制对方正在放置的反制
- 非法请求不消耗反制
- 公平不能被反制
- 整手未触发：结束返还 1（空放净成本 3）
- 对天命 100% 有效，不因「牌堆已改」而削弱

## 11 公平 / Fairness

- 负载 **4** / 费用 3 / 主动公开 / 每手 1 次
- **不能被反制**
- 成功后立即清除双方当前：
  - 主动持续状态、预埋、待结算、尚未完成的技能效果
  - 反制陷阱、血战、防守、恐吓、绝密当前保护、绝境待结算
  - 深呼吸待恢复、零化、撤退、未触发试探、伪装、Counter trap 等同类存续状态
- 本手禁止新的主动技能事件与新的被动技能事件
- 本手结束恢复全部取消，包括系统胜者 +1、败者 +2、平局双方 +1
- 不回滚：已见信息、千术 / 天命 / 重启已完成改牌、已完成筹码直接转移、已完成终局没收
- 公平成功后本手不能再发动终局；终局已关闭下注后不再生成普通公平窗口
- 违约前仅免除贷款利息，保留实际本金；不解锁、不重置次数、借款手或宽限。重复公平不继续减债，违约后对债务完全无效。
- 已取得的贷款资源不回滚；主动偿还不受技能封锁影响。

## 12 千术 / Cheat

- 负载 5 / 费用 6 / 主动 / 每手 1 次 / 可见性混合
- 用自己一张底牌交换：
  1. 对手指定底牌位置（不知牌值，受绝密）
  2. 已公开公共牌（改动会自然暴露千术）
  3. 尚未发出的未来公共牌位
  4. 下一张有效发牌
  5. 剩余未发牌堆中均匀随机一张非顶部、且排除下一张有效发牌的牌；旧底牌放回被抽位置
- 必须保持 52 张唯一。已完成交换是既定事实

## 13 绝路 / Dead End

- 负载 5 / 费用 5 / 主动公开 ALL IN / 每手 1 次
- 成功后执行当前规则允许的最大合法 ALL IN，并封锁对手本手新的主动 / 被动技能事件
- 不清除已有撤退等既定状态
- 对手之后普通 Fold：绝路方标准净收益 ×3
- 对手 Call 进摊牌：即使绝路方获胜，绝路本身不提供 ×3
- 恐吓下仍可发动，投入受 500 截断，但仍记 ALL IN 行为
- 绝路 ALL IN 对伪装强制公开
- 先绝路后不能新发动撤退；先撤退后绝路仍可撤退 Fold（此时标准净 = 0，Fold ×3 仍为 0）

## 14 灵视 / Clairvoyance

- 负载 3 / 费用 2 / 主动秘密 / 每手 1 次
- 私下读取：对手真实能量；本手截至当前已完成的技能事件（含原本秘密技能）
- 看不到：感知内容与真假、情报看了哪张、千术隐藏换牌细节、天命点名、强运私人改牌、贷款能量细节、重启抽到的牌、尚未触发的完整构筑
- **不能穿透伪装读取 stack / pot / bet / call / contribution**
- 仍可以知道「伪装这个公开技能已经发生」
- 不受绝密阻挡，可被反制

## 15 零化 / Nullification

- 负载 5 / 主动完全秘密 / 每手 1 次 / 仅 Flop 及之后
- 公共牌零化费用 6：指定已公开或尚未发出的公共牌位置，最终算牌时对双方视为不存在
- 底牌零化费用 7：系统随机对手一张底牌不参与其最佳五张；可被绝密阻止
- 双方可零化同一公共牌位置：两次都成功扣费，该牌只失效一次
- 持续状态，公平可清除。最终结算时才揭露

## 16 强运 / Fortune　**FROZEN_V1 / soft-v1.1-energy**

- 负载 5 / 被动完全秘密
- 改牌费用 3；资源强运不耗费
- 节点：底牌、Flop、Turn、River、手牌结束资源
- 底牌已足够优秀则不改底牌；较差时自动改善，玩家不能选择是否触发、换哪张、换成什么
- 公共牌强运不得读取对手底牌
- 资源强运成功时额外 +1，且不能递归再触发强运
- 允许能量降到 -4；再低则该次付费强运不发生
- 负能量时除强运外不能有新的主动 / 被动技能事件
- 均势、能量 4 时参考触发率：底牌约 7.47%，公共牌约 5.04%，资源 15.2%
- 概率范围：底牌 6%～16%、公共牌 4%～10%、资源 12%～20%。筹码/能量权重依次仍为 0.78/0.22、0.74/0.26、0.40/0.60；仅概率上限随新版自然恢复校准。
- **未解冻前不得改 soft-v1.1-energy 数值、改牌费用或 -4 下限**

## 17 天命 / Destiny

- 负载 5 / 费用 7 / 主动完全秘密
- 仅 Turn 已公开后的下注阶段、自己的行动回合
- 点名一张仍在合法可操作牌堆中的牌，立刻成为下一张真正会发出的 River（有烧牌则对应有效河牌位）
- 立即完成的牌堆修改，公平不能回滚
- 目标非法：7 费照付且失败
- 反制 100% 阻止。对手仍可 Fold，7 费不退
- 携带者能量上限 8→10，初始仍为 4；公平不能改回上限
- 本技能不设每手次数上限，但受阶段与能量约束

## 18 贷款 / Loan

- 负载 2 / 费用 2 / 主动 / 筹码公开、能量秘密。
- 每手合计最多 **2 次**；筹码分支最多 2 次，能量分支最多 1 次。分支在扣费前锁定。
- Chip + Chip、Chip + Energy、Energy + Chip 均可；任何第三次贷款均拒绝。
- 反制捕获时费用照付、消耗本次额度，但不获得资源、不生成债务、不改变债务状态；合法失败仍按回收利用规则处理。

| 分支 | 实际获得 | 正常应还 / 笔 | 一次性违约金 |
| --- | --- | --- | --- |
| 筹码（公开） | 从对手转移最多 100 | 150 | +25 |
| 能量（秘密） | 扣费后获得最多 5，受个人上限约束 | 6 | +1 |

双筹码分支保留 200 筹码贷款斩杀。每笔保存实际获得量作为本金，正常未公平调整的应还金额仍为 150 / 6。

### 债务状态与额度

| 状态 | 新借款 | 主动偿还 |
| --- | --- | --- |
| 可用：无债务 | 受当手总计与分支额度约束 | 无需 |
| 借款当手 | 可继续使用本手剩余额度 | 可按笔完整偿还 |
| 宽限：借款手已结束仍欠款 | 禁止，直到全部还清 | 可按笔完整偿还 |
| 违约 | 禁止，其他技能与扑克行动正常 | 可按笔完整偿还 |

偿还不刷新任何本手计数。借款后立即还清再借仍受本手最多两次限制。只还一笔而仍有旧债时不解除锁定。全部真实还清后立即恢复当前手剩余额度。

### 主动偿还

- 不再于下一手自动扣款，不追缴筹码收益、自然回能或技能恢复。
- 不支持任意金额或部分还款，每次完整偿还一笔。
- 偿还为独立服务器权威请求：验证座位、房间、比赛、手牌、债务、足额资源和幂等请求。
- 偿还不是技能事件：不额外付费、不占额度、不触发 Counter / Alert / Recycle、不打断 Deep Breath，不推进下注行动或重置行动时限。
- Fairness 的技能封锁不禁止偿还。
- 筹码实际转移给原贷款对手并计入经济审计。手中仅在双方均未全下且付款后仍有筹码时允许；其他情况等待安全结算窗口。结算窗口归零由正常比赛终止流程处理。
- 能量必须足额真实扣除，不允许以 Loan 偿还名义透支；Fortune 自有负能量机制不变。

### 两手宽限与违约

借款手为 N，不计入宽限。N+1 为第一宽限手，N+2 为第二宽限手。N+2 全部结算完成后仍保留正常偿还窗口，可以使用本手最终获得的筹码与能量按原金额偿还；仅在 N+2 → N+3 的手牌边界、下一手初始化前仍未偿还时违约。Showdown、普通 Fold、Tie、Retreat 均计一手；宽限仍为两手，不延长到 N+3。

对每笔未偿债务只加一次违约金，不随之后手数重复增加：
- 单筹码：150 → 175；双筹码：300 → 350。
- 能量：6 → 7。
- 不自动扣除当前或未来资源；长期不还只令本场 Loan 持续不可用。

### Fairness 与贷款

- 仅违约前免除利息，应还金额设为该笔**实际取得的本金**：通常 150 → 100、6 → 5。
- 不删除本金、不视为还款、不解除债务锁、不重置当手次数、借款手或两手宽限。
- 重复公平不继续减债；违约后公平对本金、利息、违约金全部无效。
- 公平后仍违约：100 → 125；双筹码 200 → 250；能量 5 → 6。
- 能量获得被上限截断或筹码不足 100 时，以实际到账量为本金；本金为 0 的笔也需明确偿还关闭，不能由公平自动解锁。

### 隐私、重连与比赛结束

本人私有状态包含逐笔本金、应还金额、宽限手数、公平调整、违约金与偿还资格。对手公共状态和重连视图不含秘密能量债务或偿还细节；公平公共播报不泄漏秘密贷款。

债务、违约标记、宽限与当手次数在断线重连时保持。比赛合法结束后终止全部债务，不赛后追缴、不复活败者、不逆转胜负。伪装下公开贷款只说发动，不公开资源数字。

## 19 警觉 / Alert

- 负载 1 / 费用 0 / 被动完全秘密
- 只监听敌方合法、正式提交且仍对自己隐藏的**主动**技能事件
- 公开主动、被动、非法、取消、重发都不触发
- 概率：10% → 25% → 40% → 55% → 70% → 85% → 100%
- 漏过升一级，成功后重置为 10%；敏锐度跨手保留
- 成功后不在技能瞬间提示，而在自己下一次合法下注决策开始时显示固定文案，不透露名称 / 类型 / 数量 / 费用 / 结果 / 精确时间
- 本手最多成功提示一次
- 伪装是公开主动，**绝不触发警觉**

## 20 撤退 / Retreat

- 负载 2 / 费用 3 / 主动秘密防御 / 每手 1 次
- 在自己任意合法下注窗口支付 3，秘密建立撤退状态
- 允许同一窗口立即 Fold，也允许稍后在其他合法 Fold 窗口使用
- 不要求提前一街、最小延迟、冷却

撤退 Fold：

1. 手牌结束
2. 双方本手全部标准贡献原路返还（含盲注与标准 ALL IN 贡献）
3. 标准净转移 = 0
4. 使用者不获得败者 +2；对手正常恢复 +1（公平抑制时除外）

不回滚：贷款 / 终局直接筹码、已付能量、已见信息、已完成换牌

未使用撤退 Fold：

- 正常赢：自然恢复 +1，计入撤退费用后净 -2
- 正常输：仍有败者 +2，净 -1

以上净值仅计撤退费用与自然恢复；其他技能、能量上限与公平抑制仍按各自规则处理。

被反制：3 已付，状态不建立，不自动 Fold，留在原窗口；有回收则可按规则返 1

交互：

- 先撤退后绝路：仍可撤退 Fold；0 × 3 = 0
- 先绝路：不能新发动撤退
- 公平清除状态，3 费不退
- 恐吓下不能 Fold
- 终局关闭下注后状态可仍在，但没有 Fold 窗口；终局不主动删除撤退
- 撤退 Fold 不触发试探

## 21 重启 / Restart

- 负载 4 / 费用 3 / 主动秘密 / 每手 1 次
- 两张底牌一起洗回合法剩余牌堆，再随机抽两张
- 允许抽回原来那两张。完成即既定事实
- 必须保持 52 张唯一

## 22 试探 / Probe

- 负载 1 / 费用 2 / 主动秘密 / 每手 1 次
- 对手之后主动选择**普通 Fold**：基础标准净收益 +50，再算倍率
- 例：基础 100、试探成功、血战 → `(100+50)×2 = 300`
- 自己 Fold 不触发自己的试探
- 撤退 Fold 不是普通 Fold
- 未触发状态可被公平清除

## 23 伪装 / Disguise

- 负载 4 / 费用 2 / 主动公开 / 每手 1 次
- 隐藏的是「受影响玩家能获得的筹码数值信息」，必须从玩家专属 view model / 序列化层裁剪，不能只靠 CSS

单方：发动者视角正常。受影响方看不到：

- 双方剩余筹码、筹码变化、本手累计投入
- Pot、Bet / Raise / Call 金额、最小加注、需补多少
- 「余额不足 XXX」等可反推 stack 的数字
- Call 按钮只显示「Call」；Raise 不显示 Minimum Raise 数字

超额输入：受影响方按真实最大可投入自动封顶为合法 ALL IN，不返回筹码不足数字。本人立刻知道自己是否 ALL IN，但不显示「你剩余 / 实际投入 XXX」。

普通 ALL IN：对受影响的对手伪装成普通 Bet / Raise / Call，无 ALL IN 标签 / 动画 / 特效。  
本人 ALL IN 状态始终可见，包括双重伪装。  
绝路 ALL IN 强制对双方公开。

双方伪装：进入黑暗筹码状态，仍各自知道自己的 ALL IN。

灵视不能看具体筹码数字。公开技能不触发警觉。  
公平后恢复**未来**显示，不回填已经隐藏时刻的历史数值日志。  
摊牌 / 结算画面在伪装持续期间仍隐藏 Pot 与筹码变化，只公开谁赢、牌型、手牌。

## 24 终局 / Endgame

- 负载 6 / 费用 8 / 主动公开超级技能 / 每手 1 次
- 可在自己的合法下注窗口使用，包括面对 Bet、Raise、普通 ALL IN
- 另有 Call-to-zero 专属窗口：对手合法 Call 后真实剩余筹码 == 0，且下一张公共牌尚未发出、Showdown 尚未执行
- 该窗口**只给刚刚造成 Call-to-zero 的进攻方**
- UI 必须提供「发动终局 / 放弃」；超时视为放弃
- Bot 按自身可见牌力判断，不得无脑自动发动

处决资格：仅当对手因**真实标准 ALL IN 或 Call-to-zero** 导致 remaining chips == 0。  
恐吓伪 ALL IN 若真实仍有筹码，则 execution = false。  
不能把终局没收之后才变成 0 再伪造处决。

严格顺序：

1. 确认合法
2. 支付 8
3. 处理反制。命中则失败：不没收、不锁池、不关下注、不处决、不自动发牌；有回收可返 4
4. 成功公开
5. 计算双方标准贡献，matched = min
6. 仅没收对手未匹配部分，类型为直接技能筹码转移，不进倍率
7. 匹配部分锁定，双方不能再 Bet / Raise / Call / Fold
8. 记录 execution（依据发动前真实剩余）
9. 按当前真实牌堆发完尚未发出的公共牌
10. Showdown
11. 比较最佳五张

处决摊牌：

- execution = false：完整普通比牌
- execution = true 且牌型**等级不同**：正常比较。皇家同花顺 10 > 同花顺 9
- execution = true 且等级**完全相同**：发动者直接胜，不再比内部大小 / kicker
- 专属斩杀特效只在「处决覆盖了普通内部比较」时标记 `endgameExecutionOverride`
- 本来就靠更高牌型赢，不得标斩杀

发动者自己多出的未匹配注按普通德州退还，不进没收池。

例：matched 基础 100，终局没收 700，血战 ×2 → 标准 200 + 直接 700 = 900，禁止 `(100+700)×2`。

# 4. 协议（9）

均为：负载 1 / 费用 0 / 被动秘密 / 结算。

触发条件：

1. 必须进入 Showdown
2. 最终最佳五张恰好为指定牌型
3. 自己赢得本手
4. Fold 获胜不触发
5. 若本手已有自己技能产生的其他筹码倍率，本协议不触发
6. 对手技能倍率不阻止本协议，可继续乘法叠加
7. 奖励：标准净收益 ×2

| 协议 | 对应牌型 |
| --- | --- |
| 协议--高牌 | High Card |
| 协议--对子 | One Pair |
| 协议--两对 | Two Pair |
| 协议--三条 | Trips |
| 协议--顺子 | Straight |
| 协议--同花 | Flush |
| 协议--葫芦 | Full House |
| 协议--四条 | Quads |
| 协议--同花顺 | Straight Flush；皇家同花顺也走本协议 |

终局处决比牌仍把皇家同花顺与同花顺视为不同等级（10 与 9）。协议层把两者都算同花顺。

# 5. 关键交互摘要

| 交互 | 现行结论 |
| --- | --- |
| 公平 × 反制 | 公平免疫反制 |
| 公平 × 贷款 | 违约前仅免利息、保留实际本金；不解锁、不重置宽限或次数；违约后无效 |
| 公平 × 撤退 | 清状态，3 费不退；之后不能新撤退 |
| 公平 × 伪装 | 清状态，恢复未来视图，不回填历史数字 |
| 公平 × 终局 | 公平已成功则不能发动终局；终局已关下注则不再给普通公平窗口；已没收不回滚 |
| 公平 × 零化 | 零化是持续状态，可被清除 |
| 伪装 × 灵视 | 知道伪装发生，看不到筹码数字 |
| 伪装 × 警觉 | 公开主动，不触发 |
| 伪装 × 贷款 | 公开贷款不带数字 |
| 伪装 × 绝路 | 绝路 ALL IN 强制公开 |
| 撤退 × 绝路 | 先撤后绝仍可撤；先绝后不能新撤 |
| 撤退 × 试探 | 撤退 Fold 不触发试探 |
| 撤退 × 恐吓 | 不能 Fold |
| 撤退 × 终局 | 无 Fold 窗口，状态不必删除 |
| 终局 × 反制 | 先付 8 再处理反制；命中则无没收、无处决 |
| 终局 × 血战等倍率 | 直接没收不进倍率 |
| 终局 × 协议 | 处决同级由发动者胜；协议仍看最终牌型是否恰好匹配 |

# 6. 明确不回滚的事实

以下在公平、撤退、反制失败补偿中都不是「把时间倒回去」：

- 已经看到的信息
- 千术 / 重启已完成换牌
- 天命已完成牌堆修改
- 贷款已取得的筹码或能量
- 终局已完成的直接没收
- 已支付且未被回收规则覆盖的能量
